# Tangent

A concept one-page site for a fictional design studio. No libraries, no frameworks: one HTML file, hand-written CSS and JS.

- Hand-written WebGL fragment-shader background (fbm smoke, mouse-reactive ember)
- Virtual smooth scroll, single-file SPA rooms with wipe page transitions
- Scroll-pinned horizontal work gallery with drag-to-scroll and parallax frames
- Scroll-scrubbed manifesto, variable-font hero ripple, pop-out menu, custom cursor
- Desktop, touch, and reduced-motion fallbacks
